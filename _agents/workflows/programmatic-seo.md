# Programmatic SEO Agent Workflow

This autonomous task executes on a weekly CRON schedule. Its objective is to scale `PaidToBe.com` by generating high-quality, localized, and contextually rich landing pages tailored for long-tail search queries (e.g., "AI Risk in Norway", "Cost of Living vs UBI in California").

### 1. Identify Target Edge Cases
Consult the `DATA_MODEL.md` to map regions and sub_regions that are currently missing fully fleshed-out landing pages.
- Query the `sub_regions` table for missing SEO meta descriptions.
- Identify the highest-opportunity unrepresented locations.

### 2. Scaffold Content Pages
For each target sub-region or long-tail query, generate a markdown or JSON artifact containing:
- Highly specific title tags (`<title>`) and Meta Descriptions.
- JSON-LD structured data for the location and policy entity.
- 500-1000 words of localized editorial content intersecting local cost of living against global AI exposure risks.

### 3. Commit Code Actions
If a new React Router dynamic route or static page build script is required to render these objects visually:
// turbo
Run `npm run build` and `npm run test` to verify page rendering successfully without layout breakage.

### 4. Push to Production
// turbo-all
Run `git add .` to stage the newly generated page templates and SEO models.
Run `git commit -m "feat(seo): Autogenerate [number] programmatic SEO pages for [Region]"`
Run `git push origin main` to deploy automatically via Lovable/Vercel.

### 5. Log Output
Record the generated pages into `documents/CHANGELOG.md` under the "Content" heading so the human/Solo-Founder can monitor the traffic generated by this sprint.
