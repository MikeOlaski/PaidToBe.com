# PaidToBe — Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] — 2026-03-15

### Added
- **Design System**: Source Serif 4 + Inter typography, warm editorial color palette with teal accent, semantic HSL tokens for light/dark modes
- **Seed Data**: 27 countries across 6 regions with readiness scores, UBI status, policy timelines, expat info, and workforce vulnerability data
- **Landing Page**: Hero section with animated stats, top-6 country cards, value propositions (Readiness Scores, Policy Influence, Early Alerts), membership CTA
- **Country Directory**: Search bar, region/UBI status filters, 4 sort options, responsive card grid with score badges and progress bars
- **Country Detail Pages**: 4-tab layout (Overview, Scores, Timeline, Expat Info) with key facts, industry badges, policy timeline, visa types, and tax info
- **Rankings Leaderboard**: Sortable table by 6 dimensions, click-to-compare (up to 3 countries), comparison panel with highlighted best scores
- **Membership Page**: 3-tier pricing (Free Explorer, Insider $39/mo, Strategist $399/yr) with feature lists and FAQ section
- **Methodology Page**: Scoring dimension breakdown with weights, data sources, and mission statement
- **Navigation**: Responsive navbar with mobile hamburger menu, footer with section links
- **Project Documentation**: PRD, Roadmap, Architecture, Data Model, Design System, Changelog
