# PaidToBe — Roadmap

## Phase 1: MVP Foundation ✅ (Current)
_Status: Complete_

- [x] Design system (Source Serif 4 + Inter, editorial palette, semantic tokens)
- [x] Seed data: 28 countries with readiness scores, policies, timelines
- [x] Landing page with hero, stats, value props, CTAs
- [x] Country directory with search, filters (region, UBI status), sorting
- [x] Country detail pages (Overview, Scores, Timeline, Expat Info tabs)

- [x] Project documentation (/documents)

## Phase 3: Intelligence Layer 🔲
_Target: Phase 2 + 2 weeks_

- [ ] Perplexity API connector for live news aggregation
- [ ] Per-country news feed (premium feature)
- [ ] Email alert system for policy changes
- [ ] Country watchlists (user-configurable)
- [ ] News digest email (weekly for Insider, daily for Strategist)

## Phase 4: Community & Influence 🔲
_Target: Phase 3 + 3 weeks_

- [ ] Polymarket integration (prediction odds per country)
  - Build/integrate a market betting on when a country's UBI distributions will reach 10x their median Cost of Living (or another quantifiable threshold metric).
- [ ] Odds change alerts for premium members
- [ ] Policy influence hub (petitions, civic engagement links)
- [ ] Community forum or discussion threads per country
- [ ] User-submitted policy updates (moderated)

## Phase 5: Growth & Scale 🔲
_Target: Ongoing_

- [ ] Comprehensive Global Database: Represent every single country (195+) in the database
- [ ] Sub-national Granularity: Normalize and tie data to states, provinces, and counties for localized intelligence
- [ ] Add autonomous jurisdictions (Scotland, Catalonia, Hong Kong, etc.)
- [ ] Interactive world map visualization
- [ ] SEO optimization (JSON-LD, meta tags, OG images per country)
- [ ] Autonomous Agents for Programmatic SEO (at-scale automated content generation for edge cases, hyper-local pages, and long-tail query capture)
- [ ] Newsletter/blog for editorial content
- [ ] Referral program for members
- [ ] API access for researchers (premium tier)
- [ ] Mobile app (PWA)
- [ ] Localization (multi-language support)
